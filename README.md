# JCECEB B.Sc. Nursing Practice Platform

A premium, production-grade practice platform for candidates preparing for the Jharkhand Combined (JCECEB) B.Sc. Nursing Entrance Examination.

## Features

- **10 Full-Length Mock Tests**: 1,500 total verified practice questions matching the exact style, difficulty, and chapter weightage of real JCECEB 2018–2023 papers.
- **50-50-50 Balance**: 50 Biology, 50 Chemistry, and 50 Physics questions per mock test.
- **Deep Explanations**: Every question includes a detailed concept solution, an option-by-option rationale of why other choices are wrong, and an NCERT textbook reference.
- **Interactive Timer**: A 2-hour circular countdown ring with responsive action tools optimized for mobile and desktop screens.
- **Advanced Performance Analytics**: Chapter-wise accuracy matrices, score tracking logs, and progress metrics.
- **Sleek Interface**: Built with beautiful glassmorphic designs, micro-animations, and full class-based light/dark mode support.
- **Local Profile**: Anonymous profile setup saved directly to local storage (no registration required).

## Technology Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 + Framer Motion (animations) + Lucide (icons)
- **State Management**: Zustand
- **Charting**: Recharts

## Local Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the hot-reloading development server:
   ```bash
   npm run dev
   ```

3. Build the production bundle:
   ```bash
   npm run build
   ```
